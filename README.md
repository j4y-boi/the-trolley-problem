# The Trolley Problem
This game is going to be about trying to stop the trolley problem from ever even happening.

## How to play
You can either download the desktop version (Windows/Linux only) by going to the [Releases](https://github.com/j4y-boi/the-trolley-problem/releases/tag/v0.0.7) of this repo or go to [trolley.taxfraud.dev](https://trolley.taxfraud.dev/) to play the web version. The game itself has no itch.io page at the moment, this is primarily because the game itself has no branding yet. (lol)

## Some information:
This game isn't evem remotely close to being finished, I primarily started this project as a way to learn new digital skills, I also wanted to learn how to make music and 3D models. I got the music making process figured out, the only thing now is to learn 3D modeling.

## Basic (planned) premise of the game:
You play as the bystander of [the trolley problem](https://en.wikipedia.org/wiki/Trolley_problem), you'll need to choose between hitting one person or hitting five people. After your first choice a malfunction in the game causes you to get a third choice which branches into different possibilities, which allows you to unlock different possible endings, ranging from stopping the train driver from getting to work and preventing the dillema from happening, to being in the cart yourself.
